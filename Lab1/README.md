# Лабораторная работа №1: Обработка изображений
Данная работа посвящена гистограммному и статистическому анализу цифровых изображений.

## Основные этапы работы:
1. Выделение однородных участков подстилающей поверхности (Trees, Roads, Roofs).
2. Сбор статистики (Mean) по цветовым каналам в программе IrfanView.
3. Расчет математического ожидания и дисперсии для каждого типа поверхности.
4. Построение графиков распределения яркости с помощью Python (библиотеки NumPy, Matplotlib).
5. Анализ влияния цветовых преобразований и контрастности на гистограмму изображения.

## Состав репозитория:
* `report.pdf` — итоговый отчет со всеми выводами.
* `Code/` — скрипт для обработки данных и построения графиков.
* `Images/` — исходные фрагменты и результаты преобразований.
