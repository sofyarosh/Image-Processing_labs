# Лабораторная работа №2: Семантическая сегментация аэрофотоснимков

Данная работа посвящена обучению сверточной нейронной сети (CNN) для автоматического распознавания и классификации типов подстилающей поверхности на снимках с БПЛА.

## Основные этапы работы:
1. **Выбор и подготовка данных**: Использование аэрофотоснимка высокого разрешения (16423x11782 пикселей) в формате `.tif`.
2. **Разметка данных**: Выделение опорных зон для 5 классов объектов: *Forest* (Лес), *Road* (Дорога), *Field* (Поле), *Grass* (Трава), *House* (Дома).
3. **Создание датасета**: Автоматизированная нарезка изображения на фрагменты (патчи) размером 128x128 пикселей.
4. **Решение проблемы дисбаланса**:
   - Применение аугментации (повороты, отражения) для редких классов (дороги, дома).
   - Использование `WeightedRandomSampler` для балансировки обучающей выборки.
5. **Обучение модели**: Использование архитектуры **ResNet-18** с предобученными весами. Итоговая точность (Accuracy) составила **97.8%**.
6. **Инференс и анализ**:
   - Построение карт сегментации методом скользящего окна.
   - Сравнение результатов при различных шагах сканирования (stride): 64, 128 и 256 пикселей.

## Состав папки:
* `Report_lab2.pdf` — подробный отчет с описанием методики и анализом.
* `Code/` — ноутбук Google Colab с кодом нарезки, обучения и инференса.
* `Images/` — примеры патчей, на которых обучалась нейросеть, итоговые карты сегментации с разной детализацией.

## Результаты:
В ходе работы было установлено, что нейросеть эффективно разделяет природные ландшафты, но испытывает сложности при различении спектрально близких антропогенных объектов (асфальт дорог и крыши домов). Экспериментально доказано, что уменьшение шага сканирования до 64 пикселей значительно повышает качество границ объектов на итоговой маске.
